# MRTLS

مشروع رقمي تجريبي قابل للتشغيل مباشرة من المتصفح.

## المزايا
- لوحة تحكم عربية RTL.
- إدارة وإنشاء وحذف المشاريع.
- حالات للمشاريع: نشط، مكتمل، متوقف.
- بحث فوري.
- سجل نشاط.
- وضع فاتح وداكن.
- حفظ البيانات محليًا عبر LocalStorage.
- تصميم متجاوب للكمبيوتر والهاتف.

## التشغيل
افتح `index.html` في المتصفح.

## الملفات
- `index.html` الواجهة.
- `style.css` التصميم.
- `app.js` منطق التطبيق.

هذه نسخة تجريبية Frontend فقط، ويمكن تطويرها لاحقًا إلى نظام حقيقي بإضافة قاعدة بيانات وAPI وتسجيل دخول وصلاحيات.
